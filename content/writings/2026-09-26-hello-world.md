# Hello, world

This is an example post. Every post is one markdown file in `content/writings/`, named with its date and a short slug, like `2026-09-26-hello-world.md`. The date orders the list on the writings page, and the slug becomes the address: this post lives at `/writings/hello-world`.

The first heading is the post's title. Everything else is plain markdown: *italics*, **bold**, [links](https://en.wikipedia.org/wiki/Markdown), lists, and quotes.

To publish a post, add a file and push. To take one down, delete it.
