# Making this website

This website was made with AI. That's unusual for me - in the past I've always coded my personal websites by hand. 

It hurt a little bit to give this up, but I want to try and start prioritizing speed more. My biggest problem has always been not having enough time to do the things I want to do, so now that tools exist to speed up these kinds of more menial tasks, I should probably use them. 

[My older website](https://dudugan.github.io) is still almost all hand-coded, though, and will remain that way. It feels like hand-coding has now become an art form, and practicing it is sort of meditative. It's not something I want to completely lose. 

I have a running folder of personal websites that I like, and this website was particularly inspired by two of them: the super minimalist [website of Galen Mead](https://nel.ag/) and the very beautiful [website of Jia Chen](https://www.jia.build/). 

I've tried to saddle this website with as few expectations as possible. Over time, we'll see where it grows.
