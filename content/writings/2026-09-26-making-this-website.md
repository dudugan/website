# Making this website

This website was made with AI. That's unusual for me - in the past I've always coded my personal websites by hand. 

It hurt a little bit to give this up, but I want to try and start prioritizing *speed* more. My biggest problem has always been not having enough time to do the things I want to do, and so when the tools exist to speed more menial things up, I should probably use them. 

I have a running folder of personal websites that I like, and this website was particularly inspired by three of them: the uber-minimalist [website of Galen Mead](https://nel.ag/) and the deeply beautiful [website of Jia Chen](https://www.jia.build/). 

(Note that [my older website](https://dudugan.github.io) is still almost all hand-coded.)
