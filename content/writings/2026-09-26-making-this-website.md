# Making this website

This website was made with AI. That's unusual for me - in the past I've always coded my personal websites by hand. 

It hurt a little bit to give this up, but I want to try and start prioritizing *speed* more. My biggest problem has always been not having enough time to do the things I want to do, and so when tools exist to speed more menial tasks up, I should probably use them. 

I have a running folder of personal websites that I like, and this website was particularly inspired by two of them: the super minimalist [website of Galen Mead](https://nel.ag/) and the very beautiful [website of Jia Chen](https://www.jia.build/). 

Note that although the metaphor on the homepage is from Minecraft, I actually only played Minecraft for about a year when I was younger. 

Also note that [my older website](https://dudugan.github.io) is still almost all hand-coded. It feels like hand-coding has now become an art form, and practicing it is sort of meditative. 

Finally, note that I really need to get back into the practice of daily writing, so posts like flow better and are not just lists of notes.
